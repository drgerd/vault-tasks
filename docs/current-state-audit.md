# Project history

The project began as a local vault-task query utility and now includes an
opt-in archive command. Historical environment observations and real-vault
validation details are intentionally not included in this public repository.

For current behavior, use the README and the focused product documents:

- [Query mode](query-mode.md)
- [Archive mode](archive-mode.md)
- [Architecture](architecture.md)

Automated tests use only synthetic Markdown fixtures. Local configuration and
real vault data must remain outside Git.
